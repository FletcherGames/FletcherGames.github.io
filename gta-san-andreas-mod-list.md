# FletcherGames - GTA San Andreas Mod List

**Inventory date: November 19, 2026.** Classic PC San Andreas.

This is a curated list of mods present in my GTA San Andreas installation, with mod pages and creator links. Entries that only had search links have been removed. Six sources were supplied directly by FletcherGames. **It is not an installation guide or a tested compatibility pack.** Presence on disk does not prove a mod is active, conflict-free, or the same version as the linked download.

All mods belong to their respective creators. Download from their pages and follow their requirements. This document redistributes no mod files. Creator pages may require an account or payment; access and availability can change.

## Reading the links

- **Mod page / Author repository:** a matching public listing or project was located; installed build equivalence is not guaranteed.
- **Installed documentation:** URL supplied with the installed files; not a guarantee it still serves the same download.
- **Listed source:** public source link found in an existing mod index; not independently confirmed as the exact installed build.
- **Creator hub / Related release / Framework page only:** useful starting point, not an exact download claim.
- **Sources supplied by FletcherGames:** the glass, CJ clothing, fireflies, Jolt Physics, SleekBlood, and Better Cars links were identified directly by the owner of this installation.

## CLEO supporting plugins

Installed classic CLEO plugins: **CLEO+, FileSystemOperations, IniFiles, IntOperations, NewOpcodes.** The [Essentials Pack](https://www.mixmods.com.br/2019/06/sa-essentials-pack/) is a documented source for the common setup, but contents/version may differ from this installation.

The Redux plugin folder also contains: dylib, Events, Frontend, FxtLoader, IdeLoader, IniFiles, Input, MemoryOperations, TextLoader, plus SA.Audio, SA.DebugUtils, SA.FileSystemOperations, SA.GameEntities, SA.IniFiles, SA.Input, SA.Math, SA.MemoryOperations and SA.Text. Some include both 32-bit and 64-bit variants. Their presence is not proof they all load in this 32-bit game. Start with [CLEO Redux](https://re.cleo.li/) for compatible runtime/plugin documentation; exact standalone sources for the SA-prefixed files are unresolved.

Living Streets launcher folders are also present; an old launcher may be a migration stub rather than a second copy of the mod.
