# FletcherGames - GTA San Andreas Mod List

**Inventory date: November 19, 2026.** Classic PC San Andreas.

This is an inventory of the files currently present in my GTA San Andreas installation, with mod pages, creator hubs, and clearly marked unresolved sources. **It is not an installation guide or a tested compatibility pack.** Presence on disk does not prove a mod is active, conflict-free, or the same version as the linked download.

All mods belong to their respective creators. Download from their pages and follow their requirements. This document redistributes no mod files. Creator pages may require an account or payment; access and availability can change.

## Reading the links

- **Mod page / Author repository:** a matching public listing or project was located; installed build equivalence is not guaranteed.
- **Installed documentation:** URL supplied with the installed files; not a guarantee it still serves the same download.
- **Listed source:** public source link found in an existing mod index; not independently confirmed as the exact installed build.
- **Creator hub / Related release / Framework page only:** useful starting point, not an exact download claim.
- **Unresolved / Collection:** exact source could not be established. Search links are discovery links, not verified downloads.

Start with [CLEO Redux](https://re.cleo.li/) for compatible runtime/plugin documentation; exact standalone sources for the SA-prefixed files are unresolved.

The CLEO `_disabled` folder contains **BCHPT.cs**, **ImGuiReduxWin32.cleo**, and **ImGuiReduxWin64.cleo**; these are kept separate from the installed-mod inventory. Source of BCHPT.cs is unresolved. Living Streets launcher folders are also present; an old launcher may be a migration stub rather than a second copy of the mod.

- **vorbisFile.dll** is present as a potential ASI-loading entry point, but its implementation was not established from the filename. No particular loader release is attributed to it.
